# 剩余电流动作保护器（漏电保护）（摘编）

依据 GB/T 6829《剩余电流动作保护器（RCD）的一般要求》、GB/T 13955《剩余电流动作保护装置安装和运行》及施
工现场临时用电安全技术标准整理。
一、分级保护（选择性配合）
位置                                  额定动作电流            分断时间
末级（开关箱/插座回路）                        ≤30mA             ≤0.1s
分配电箱                                ≥末级 3 倍（≤300mA）   ≤0.3s
总配电箱                                ≥分配 3 倍（≤500mA）   ≤0.5s
总配电箱 RCD 额定剩余动作电流 >30mA、动作时间 >0.1s，但动作电流与动作时间乘积 ≤30mA·s。
二、特殊场所
潮湿或有腐蚀介质场所：防溅型产品，额定剩余动作电流 ≤15mA，动作时间 ≤0.1s；
卫生间插座：防水插座或加装防水盒，安装在 0 区和 1 区以外。
三、安装要求
1. 装设在总配电箱、开关箱靠近负荷一侧，不得用于启动电气设备操作；
2. 电源侧、负荷侧端子接线正确，不得反接；
3. 灭弧罩安装牢固，电弧喷出方向留飞弧距离；
4. 控制回路铜导线截面 ≥2.5mm²；
5. 端子处中性导体（N）严禁与保护接地导体（PE）连接，不得重复接地。
四、检测与维护
每月用专用仪器检测动作特性不少于 1 次；
每天使用前启动试验按钮试跳一次，试跳不正常不得继续使用；
搁置已久重新使用或连续使用的，逐月检测特性。
五、民用建筑分级保护（A/B 方式）
A 方式：供电公司电表箱前装可报警式四极四线 RCD，S 型（延迟型），整定 300mA 或 500mA；
B 方式：每个用户电表后出线处装 S 型 RCD，整定 100mA；
第一级保护为故障保护兼电气火灾保护。
六、TN-S 系统要求
低压用电系统采用 TN-S 系统，配电采用"一机一闸一保护"；
电气设备外露可导电部分与 PE 可靠连接；
保护导体（PE）黄绿双色，中性导体（N）淡蓝色；
保护导体在插座之间不得串接，严禁重复接地。
