# 高压开关柜五防与运行维护（摘编）

依据 DL 538《高压开关设备和控制设备的操作装置》、DL/T 593《高压开关设备通用技术条件》及环网柜相关技术规范
整理。
一、"五防"功能
1. 防止误分、误合断路器；
2. 防止带负荷分、合隔离开关（插头）；
3. 防止带电合接地开关；
4. 防止带接地开关送电；
5. 防止误入带电间隔。
二、联锁要求
进出线柜应装带电显示装置，线路侧带电时闭锁接地开关及电缆室门；
电缆室门与接地开关应同时具备电气联锁和机械闭锁；
电气闭锁应单独设置电源回路，与其他回路独立；
负荷开关合闸时接地开关操作孔应机械锁死，反之亦然；
柜门仅在接地开关合闸且插入绝缘隔板后方可打开；柜门开启时负荷开关无法合闸；
断路器柜应具有防跳装置，电磁操作机构应具有脱扣自我保护功能；
严禁私自拆除联锁装置违规操作。
三、绝缘与气体要求
主回路对地、相间绝缘电阻 ≥1000MΩ（2500V 兆欧表，20℃）；
SF6 环网柜气压标准值 0.04MPa（20℃表压），年泄漏率 ≤1%；
高压系统接地电阻 ≤4Ω，低压系统 ≤10Ω；柜体接地电阻 ≤0.1Ω。
四、巡视检查项目
1. 外观：编号清晰（双重编号）、柜体无变形下沉、柜门关闭良好、螺栓齐全；
2. 表计及带电显示：断路器/手车位置、储能、带电显示指示灯正常，机械分合闸指示与实际相符；
3. 充气式开关柜气压正常，SF6 断路器气压正常；
4. 后柜：CT 表面清洁无裂纹放电，绝缘护套完整，绝缘挡板清洁；
5. 联锁装置：机械联锁润滑良好、受力部件无碎裂变形、程序锁正确、电气联锁正确。
五、运维周期
每半年一次红外测温，排查母线搭接处、断路器触头发热；
每年停电检修清扫、紧固接线螺栓、复测绝缘电阻、校验继保定值；
满负荷开断 100 次后：检查主回路电阻、动/静触头磨损（烧蚀深度超 1mm 需更换）；
无负荷开断 2000 次后：测试机构性能。
六、常见故障
1. 触头过热：螺栓松动、接触面氧化、超负荷 → 停电打磨处理重新紧固；
2. 保护误跳闸：整定值偏小、线路漏电接地、电磁干扰 → 重新整定、屏蔽电缆单点接地；
3. 柜内凝露绝缘下降：防潮除湿、封堵电缆孔洞；
4. 断路器无法合闸：机构卡涩、储能故障、联锁未复位；
5. 放电异常：螺栓松动搭接不良、绝缘件不合格、空气间隙过小（40.5kV 相间净距应达 300mm）。
