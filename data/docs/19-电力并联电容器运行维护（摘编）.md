# 电力并联电容器运行维护（摘编）

依据 DL/T 596《电力设备预防性试验规程》、GB/T 12747《电力电容器技术条件》及并联电容器运行维护规程整理。
一、正常运行参数
电容值偏差不超过额定值的 -5%~+10%，不应小于出厂值的 95%；
三相容量分配误差不超过一相总容量 5%；
三相运行电流偏差不超过平均值的 ±5%；
外壳温度不超过 50℃（部分规程 ≤60℃，持续 >70℃ 需检查散热）；
环境温度：室温 ≤40℃ 且 ≥-25℃；
极对壳绝缘电阻 ≥2000MΩ（部分要求 ≥500MΩ~1000MΩ）。
二、巡视检查项目
1. 瓷绝缘子无破损裂纹、放电痕迹，表面清洁；
2. 外壳无鼓肚、膨胀变形、接缝开裂、渗漏油，内部无异声；
3. 母线及引线不过紧过松，连接处无松动过热；
4. 熔断器、接地装置、放电回路及指示灯完好；
5. 串联电抗器线圈无变形、无放电焦味，油电抗器无渗漏油；
6. 室温不超限，门窗关闭严密，照明通风良好。
三、退出运行条件（发现以下情况之一应立即退出）
1. 外壳明显鼓肚和漏油；
2. 套管、支持绝缘子闪络放电或损坏；
3. 示温蜡片熔化；
4. 装置中有不正常响声或火花；
5. 端头接线处烧灼过热。
外壳膨胀严重者（100kvar 以下每面膨胀量 >10mm；100kvar 及以上 >20mm）应立即停止使用。鼓肚变形超过
3mm 视为严重缺陷。
四、渗漏油与外壳变形处理
渗漏油常发生在下底部、上盖边沿滚焊焊缝、注油孔、铭牌/搬运把手焊接处、套管结合面；
轻微渗漏可用锡铅焊料、环氧树脂补焊或钎焊，严重漏油或裂缝应更换；
外壳鼓胀不可修复，只能更换（内部局部放电、绝缘油产气或介质老化分解致压力增大）。
五、保护配置
串联电抗器电抗率常规选 6%（抑制 5 次及以上谐波）或 12%（抑制 3 次谐波），限制涌流和谐波放大；
熔断器熔体额定电流 ≤ 电容器额定电流 1.3 倍；
电网电压长期超过电容器额定电压 10% 时应退出运行。
六、预防性试验（DL/T 596，周期 1~3 年）
极对壳绝缘电阻：2500V 兆欧表，≥1000MΩ（部分规程 ≥2000MΩ）；
电容值测量：三相电容偏差 ±5%，单台变化不超过出厂值 ±3%；
电容器组工作电流超 1.3 倍额定电流应分析原因。
七、维护周期
室内电容器组每年至少停电维修一次，半露天/户外每半年至少一次；
每季度停电清扫（干燥压缩空气 ≤0.4MPa，粉尘严重用无水乙醇擦拭）；
运行后每年测量一次谐波；
坚持周期性维护的电容器组平均寿命 15 年以上，缺乏维护仅 8~10 年。
八、事故处理注意
维护前每台电容器必须放电；
运行中开关跳闸不允许自行试送，检查无异常并经调度同意后试送一次；
多根熔丝熔断或"群爆"或单台熔丝重复熔断，查明原因并用备品更换后方可投运。
