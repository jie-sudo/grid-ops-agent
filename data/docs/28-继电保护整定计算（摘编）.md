# 继电保护整定计算（摘编）

依据 DL/T 584-2017《3kV~110kV 电网继电保护装置运行整定规程》、GB/T 50062《电力装置的继电保护和自动装置
设计规范》整理。
一、"四性"要求（整定根本准则）
原则      定义                                          整定要点
选择性     仅由故障设备/线路本身保护动作，尽量缩小停电范围                    阶梯形配合，下级延时 < 上级延时 - Δt
速动性     满足选择性前提下尽可能快速动作                             主保护（差动、距离Ⅰ段）0 秒或极短延时
灵敏性     对保护范围内故障的反应能力                               灵敏系数 Ksen 校验，最小运行方式下校验
可靠性     该动可靠动作、不该动不误动                               躲过最大负荷、励磁涌流、自启动电流
时间级差：微机型 Δt ≥0.2s，电磁型 Δt ≥0.3s；
灵敏系数：过流保护本线路末端 Ksen ≥1.5；差动保护内部故障 Ksen ≥2.0；距离/零序按规程取 1.3~1.5。
二、电流速断保护（Ⅰ段）
整定公式：Idz1 = Kk × I(3)d,max（Kk 可靠系数取 1.3~1.5，躲线路出口最大三相短路电流）。动作时间 0~0.15s。须
躲过配电变压器励磁涌流（此时 Kk 可取 5~10 倍），采用励磁涌流闭锁可降低定值提高灵敏度。
三、定时限过流保护（Ⅱ/Ⅲ段）
整定公式：Idz2 = (Kk / Kf) × Ifh,max（Kk 取 1.2~1.3，Kf 返回系数取 0.85~0.95，Ifh,max 最大负荷电流）。动作时
间按阶梯原则逐级增加 Δt（0.3~0.5s）。
四、变压器差动保护
纵差启动电流定值 > 正常差动不平衡电流，按低压侧金属性故障 ≥2 倍灵敏度校核；
差流门槛：Icd = Kk × (Ker + Kst + Kunc) × Ie2（Ker CT 误差 0.1，Kst 饱和系数 1.0~2.0，Kunc 调压误差
0.05~0.1）；
躲励磁涌流：二次谐波制动或间断角制动；
考虑接线组别（如 Yd11）相位补偿：低压侧电流相位旋转 30° 并幅值补偿；
CT 断线闭锁比率差动一般投入，CT 断线后差流达 1.2Ie 时出口跳闸。
五、失灵保护整定（双母线）
启动判别元件：相电流、零序、负序电流，按末端单相接地灵敏度 ≥1.5 整定；
动作时序：0.15s 跟跳 → 0.25~0.3s 跳母联 → 0.5s 切除失灵断路器所在母线所有断路器；
非电量保护不启动失灵保护。
六、变压器中性点零序保护
零序电流按两段整定，零序Ⅰ段宜带方向，按与出线接地距离或零序非末段配合整定，保证母线故障灵敏度 ≥1.5。
七、投入前校验（DL/T 584）
1. 选择性校验（上下级配合正确）；
2. 灵敏性校验（最小运行方式 Ksen 满足）；
3. 躲负荷校验、躲涌流校验；
4. 时间配合校验（满足级差）。
八、常见整定错误
1. CT 变比误用（"三对照"：图纸-实物-定值单）；
2. 基准容量选择错误（220kV 及以上 1000MVA、110kV 100MVA、10kV 10MVA）；
3. 忽略最大/最小运行方式变化（最小方式校灵敏性、最大方式校选择性）；
4. 变压器接线组别未正确补偿（差流超标）；
5. 配网仅按三相短路整定，忽略占比 80% 以上的单相接地故障。
