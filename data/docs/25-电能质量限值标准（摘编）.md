# 电能质量限值标准（摘编）

依据 GB/T 14549《电能质量 公用电网谐波》、GB/T 12325《供电电压偏差》、GB/T 15543《三相电压不平衡》、
GB/T 15945《电力系统频率偏差》、GB/T 12326《电压波动和闪变》、GB/T 24337《公用电网间谐波》整理。
一、频率偏差（GB/T 15945-2008）
标称频率 50Hz，正常运行条件下频率偏差限值 ±0.2Hz，系统容量较小时可放宽到 ±0.5Hz。电网容量 300 万千瓦及以
上 ±0.2Hz，以下 ±0.5Hz。
二、电压偏差（GB/T 12325-2008）
电压等级                        允许偏差
35kV 及以上                    正、负偏差绝对值之和 ≤ 标称电压 10%
20kV 及以下三相                  ±7%
220V 单相                     +7%，-10%
三、三相电压不平衡（GB/T 15543-2008）
公共连接点负序电压不平衡度：正常运行 ≤2%，短时 ≤4%；
每个用户引起该点负序电压不平衡度允许值：一般 1.3%，短时 2.6%；
低压系统零序电压限值暂不规定，但各相电压须满足 GB/T 12325。
四、公用电网谐波（GB/T 14549-93）
电压总谐波畸变率（相电压）限值：
标称电压                 电压总谐波畸变率           奇次含有率        偶次含有率
0.38kV               5.0%               4.0%         2.0%
6~10kV               4.0%               3.2%         1.6%
35~66kV              3.0%               2.4%         1.2%
110kV                2.0%               1.6%         0.8%
220kV 电网及其供电用户参照 110kV 执行。谐波源产生的电压总谐波畸变率限值：0.38kV 为 2.6%、6~10kV 为
2.2%、35~66kV 为 1.9%、110kV 为 1.5%。
五、电压波动和闪变（GB/T 12326-2008）
长时间闪变值 Plt：≤110kV 时 Plt=1；>110kV 时 Plt=0.8（测量周期一周 168h）。
六、分布式光伏接入补充要求
公共连接点三相电压不平衡度 ≤2%（短时 ≤4%），由各光伏引起 ≤1.3%（短时 2.6%）；
注入直流电流分量 ≤ 交流额定值 0.5%；
防孤岛保护动作时间 ≤2 秒；
并网点功率因数：0.4kV 并网 0.95（超前/滞后）可调；10kV/35kV 并网 0.9（超前/滞后）连续可调。
