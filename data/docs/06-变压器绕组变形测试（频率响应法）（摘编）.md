# 变压器绕组变形测试（频率响应法）（摘编）

依据 DL/T 911《变压器绕组变形的频率响应分析法》整理。变压器绕组可等效为电阻、电感、匝间电容、对地电容构成
的无源线性二端口网络；绕组变形时分布参数改变，频响曲线出现峰值偏移、谐振点增减、曲线畸变。
一、测试原理与参数
向绕组输入端输入幅值恒定、频率连续变化的扫频正弦信号，采集输出端信号幅值，生成幅频、相频特性曲线。标准扫频
频段 1kHz~1MHz，扫频点数不少于 2000 点（关键设备可提高至 32000 点）。
传递函数：H(f) = 20lg[V2(f)/V1(f)]
二、分频段定义
频段                       符号                  频率范围
低频段                      RLF                 1 kHz~100 kHz
中频段                      RMF                 100 kHz~600 kHz
高频段                      RHF                 600 kHz~1000 kHz
三、相关系数判据（DL/T 911）
变形程度                  判据
严重变形                  RLF < 0.6
明显变形                  1.0 > RLF ≥ 0.6，或 RMF < 0.6
轻度变形                  2.0 > RLF ≥ 1.0，或 0.6 ≤ RMF < 1.0
正常绕组                  RLF ≥ 2.0、RMF ≥ 1.0、RHF ≥ 0.6 同时满足
另一常用口径（1~500kHz 频段相关系数 R）：R>0.95 无可见变形；R≈0.9 轻微变形；R 明显小于 0.9 较严重变
形，甚至匝间、饼间短路。
四、纵向与横向比较
纵向比较：同一绕组不同时期曲线叠加比较（需出厂指纹/历史曲线），灵敏度高、准确性好；
横向比较：同一变压器 A、B、C 三相互相比较（或同厂同期同型号），适用于无原始曲线场景，但三相发生相似变
形时无法判断。
判读原则：以纵向比较为主、横向比较为辅；波形观察为主、相关系数判断为辅。
五、频响曲线特征与故障对应
峰值点数减少、起伏幅度变小、向低频方向移动 → 局部变形（如 10kV/35kV 内柱绕组受挤压）；
峰值点向高频方向移动 → 110kV/220kV 外柱绕组受向外拉张力变形；
曲线严重毛刺 → 分接开关触头严重烧伤、绕组焊头/导电杆接触不良；
不同分接位置频响相关性变坏 → 调压绕组变形或分接开关故障。
六、短路阻抗验证
相关系数不好时，须辅以阻抗电压法验证。阻抗电压变化高于 4% → 绕组已严重变形，应立即退出运行；高于 2% → 应
引起足够重视。
七、现场试验注意事项
1. 测试线须悬空，避免贴近接地金属构件引入额外分布电容；
2. 分接位置与基准一致，避免曲线整体偏移误判；
3. 接线方式前后一致；
4. 测量前对铁芯消磁（消除剩磁对低频段影响）；
5. 单绕组重复测试 2 次，曲线相关系数 ≥0.99 判为数据有效；
6. 保存工况信息（分接位置、接线方式、油温、绕组编号）便于复现。
