# 防雷接地装置（摘编）

依据 GB 50169-2016《电气装置安装工程接地装置施工及验收规范》、GB/T 50065《交流电气装置的接地设计规
范》、GB 50057《建筑物防雷设计规范》整理。
一、输电线路杆塔接地电阻限值
土壤电阻率 ρ(Ω·m)             ≤100        100~500       500~1000   1000~2000   >2000
埋设深度(m)                  自然接地        ≥0.6          ≥0.5       ≥0.5        ≥0.3
接地电阻(Ω)                  ≤10         ≤15           ≤20        ≤25         ≤30
城区人口密集地区接地电阻宜小于 4Ω；
有地线的线路雷季干燥时，每基杆塔不连架空地线的接地电阻不宜超过 10Ω；
土壤电阻率 >1000Ω·m 可采用降阻剂或置换土壤；
人工接地体宜采用 Φ12 镀锌圆钢，埋深 0.5~0.8m。
二、变电站接地网
有效接地和低电阻接地系统：R ≤ 2000/IG（IG 接地故障电流）；
不接地、谐振接地、高电阻接地系统：R ≤ 120/Ig 且 ≤4Ω；
110kV 及以上变电站主接地网接地电阻一般 ≤0.5Ω。
三、配电站与用户接地
配电站（室内站、箱式变、柱上变）高低压电气装置公用接地装置，接地电阻 ≤4Ω；
低压配电 PE 线/PEN 线每个重复接地装置 ≤10Ω；
低压用户保护接地 ≤10Ω。
四、防雷接地（GB 50057）
对象                                      冲击接地电阻限值
独立接闪杆/架空接闪线/接闪网                         每引下线 ≤10Ω
一类防雷建筑                                  ≤10Ω
二类防雷建筑                                  ≤20Ω
三类防雷建筑                                  ≤30Ω
35kV 架空线路杆塔                             ≤15Ω
烟囱、水塔避雷针                                ≤30Ω
架空引入线瓷瓶铁脚                               ≤20Ω
土壤电阻率低于 3000Ω·m 地区，冲击接地电阻不应大于 30Ω。
五、避雷针（工频接地电阻）
变电所室外单独避雷针一般 ≤10Ω；构架上避雷针 ≤10Ω（满足困难时可与主接地网连接）；
防雷接地与主接地网连接时，地下连接点至 35kV 及以下设备主接地网连接点距离沿接地体 ≥15m。
六、10kV 中性点接地方式
1. 中性点经低阻抗接地；
2. 中性点不接地；
3. 中性点经消弧线圈（谐振）接地。
选择原则：架空线路单相接地电容电流 ≤10A 可用不接地；>10A 且需接地故障运行应采用谐振接地；电缆线路同理
（>10A 宜谐振接地）。
七、接地运维判定参考
合格：≤4Ω（10kV 配网）、≤0.5Ω（110kV 及以上主接地网）、≤10Ω（低压用户）；
关注：4~10Ω / 0.5~2Ω / 10~30Ω，加强季度监测；
异常：10~30Ω / 2~5Ω / 30~100Ω，建议 1 个月内整改；
严重：≥30Ω / ≥5Ω / ≥100Ω，工频短路无法正常散流，立即停运整改。
