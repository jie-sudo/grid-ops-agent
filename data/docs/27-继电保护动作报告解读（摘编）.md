# 继电保护动作报告解读（摘编）

依据继电保护运行管理导则及保护装置动作报告分析实践整理。
一、动作报告包含的四类信息
一份完整的保护动作报告包含四类信息，按顺序看能快速定性：
1. 动作时间：精确到毫秒，是判断保护配合是否正确的基准；
2. 动作元件：列出启动的判据（如接地距离Ⅰ段、零序过流Ⅱ段），决定故障性质；
3. 故障测距：从装置安装处算起的公里数，用于定位故障位置；
4. 开入开出变位记录：说明跳闸出口、重合闸出口、闭锁信号等是否按预期动作。
二、动作时间参考（判断保护配合）
保护类型                     参考动作时间
主保护                      40 毫秒以内动作出口
近后备                      300~500 毫秒
远后备                      更长
若主保护动作时间接近后备保护量级，说明主保护可能拒动或启动元件有问题。
三、动作报告 vs 事故追忆（不要混淆）
动作报告                       事故追忆
内容             结论性记录：动作元件、动作时间、测距、变位      动作前后一段时窗内的采样与开入量
数据量            小，保存上百条                    大，保存几十条
回答的问题          保护做了什么                     故障过程中发生了什么
怀疑保护误动 → 看事故追忆里的电流电压波形，确认故障量是否真实、是否达到定值；
只确认保护是否正确动作 → 看动作报告就够了。
四、常见保护类型
保护类型                作用
差动保护                比较被保护元件两侧电流，区内故障时差流大，动作
零序过流保护              反映接地故障，零序电流大于定值时动作
过流保护                电流大于定值时动作，作后备保护
距离保护                通过阻抗测量判断故障距离，分段整定（Ⅰ段约保护全长 70%）
瓦斯保护                变压器内部故障产生气体，反映油浸式设备内部故障
纵联保护                线路两侧通过通信通道交换信息，快速切除全线故障
五、保护动作报告解读要点
1. 检查保护起动绝对时间（故障实际发生时间），其他相对时间以此为准；
2. 检查故障相别与故障电流：故障相别是发生故障的相别，不等于开关动作的相别；
3. 检查动作相别与动作元件、重合闸情况：单相故障+单相重合闸方式时，动作相别应为单相，重合闸应启动；
4. 检查故障测距：测距很小说明故障点离站端近，应特别注意站内设备；测距只能当参考（线路分支、互感器变比、参
数录入会影响测距），不能当结论。
六、二次回路两点接地的危害
电流互感器二次回路应一点接地。若出现两点及以上接地点，一次系统接地故障时会在两接地点间产生电位差，形成分流
回路，使通入保护装置的零序电流产生较大偏差，可能导致零序过流、差动、母差等保护误动作，威胁供电可靠性。这是
继电保护不正确动作的常见原因，应通过绝缘检查（逐芯排查）发现并消除。
