# 电力设备预防性试验规程（摘编）

依据 DL/T 596-2021《电力设备预防性试验规程》整理，适用于 750kV 及以下交流电力设备。预防性试验旨在排查绝缘
缺陷（受潮、老化、气泡、杂质、裂纹），验证电气性能，支撑状态检修，实现从事后维修到事前预警的转变。
一、基本原则
1. 合规性：遵循 DL/T 596-2021、GB/T 7354（局放测量）、IEC 60270 等标准；
2. 安全性：停电、验电、接地、设围栏、专人监护，防过压过流；
3. 时效性：按周期执行，新设备投运 1 年内完成首次试验；
4. 可比性：数据与历史值、同类型设备对比，结合环境（温湿度＜80%）分析。

3. 电力电缆（XLPE/充油）
绝缘电阻（无显著下降，66kV 及以上 ≥1000MΩ·km）、直流耐压/泄漏电流（无击穿、泄漏电流稳定）、局部放电
（无异常脉冲）、外护套绝缘（≥1MΩ·km），周期投运前 / 3~5 年。
4. 互感器
绝缘电阻 ≥1000MΩ、tanδ 符合限值；变比误差 ≤准确度等级限值；局部放电 <5pC（电磁式）；交流耐压按出厂
85%。
5. 避雷器
绝缘电阻 ≥2000MΩ（10kV）；直流参考电压/泄漏电流符合厂家值；运行电压下电流无异常增大。周期 1~3 年 / 雷雨
前。
6. 接地装置
接地电阻符合设计要求。
三、试验周期要求
220kV 及以下电压等级电力用户电气设备宜每 3 年进行一次预防性试验，最长不得超过 6 年。110kV 以下高压电气设
备、变压器、电力电缆、继保装置、断路器、互感器、避雷器、接地装置、直流屏、电容器等一般每年一次；绝缘安全工
器具每年/每半年一次。
四、常见事故警示
变压器绝缘油劣化未及时发现 → 绕组间短路着火爆炸；套管末屏接地不良 → 悬浮放电喷油着火；电缆接头绝缘下降 →
两相短路着火。
