# 静止无功发生器 SVG 运行维护（摘编）

依据 GB/T 15576《低压成套无功功率补偿装置》、DL/T 1010《高压静止无功补偿装置》、GB/T 35726《并网型微电
网用静止无功发生器技术规范》整理。SVG 采用自换相桥式电路，通过调节输出电压幅值和相位实现动态无功补偿。
一、运行参数要求
电压波动 ≤ 额定值 ±10%，电流 ≤ 额定值 1.1 倍；
功率因数维持 ≥0.95；
功率单元室内温度 ≤35℃，SVG 室温度 ≤40℃；
输出电流谐波符合 GB/T 14549 要求。
二、运行模式
模式                           说明
恒无功模式                        设定固定无功输出值
恒电压模式                        调节无功维持并网点电压稳定
恒功率因数模式                      按有功负荷自动调节无功，稳定功率因数
有源滤波模式                       检测负荷谐波，减小谐波污染
三、性能指标
响应时间 ≤20ms 启动调节，容性↔感性切换 ≤50ms；
无功调节范围 -100%~100% 额定容量连续可调，调节精度 ≤1% 额定容量；
输出电流 THD ≤3%（10kV 及以上）/≤5%（低压）；
功率因数补偿后 ≥0.95，补偿后电压波动 ≤±2%。
四、故障穿越（新能源并网）
低电压穿越（LVRT）：电压跌落至 0% 时保持并网 ≥150ms，跌落期间输出容性无功 ≥1.5 倍额定容量/每 1% 电压
跌落；
高电压穿越（HVRT）：电压 ≤110% 正常运行，110%~130% 至少维持并网 1s。
五、保护功能
过流保护动作 ≤200ms；过压/欠压保护动作 ≤500ms；过温保护、缺相保护自动切除；过温保护阈值通常 85℃ 停机。
六、巡视检查
1. 柜体无变形、损坏、脏污，紧固件无松动；
2. 监控屏运行参数正常，无异常报警；
3. 通风散热系统正常，室内温度 ≤40℃；
4. 电力电缆、控制电缆无损伤，端子连接牢固；
5. 无异常响声、振动及异味。
七、维护
定期检查电力电子器件（IGBT）、电抗器等核心部件，排查过热、异响；
常态化谐波检测，及时调整补偿参数；
记录谐波含量、补偿电流、设备损耗等运行数据。
