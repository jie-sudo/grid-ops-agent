# 配电台区线损异常排查（摘编）

依据国网公司同期线损管理规程及台区降损治理实践经验整理。
一、台区线损异常的主要原因
1. 计量故障：关口计量装置故障、互感器变比错误、表计接线错误；
2. 档案不符：用户档案与实际不一致、户变关系错误（低压用户挂接错误台区）；
3. 私拉乱接 / 违约用电：下户线破损漏电、表计体外流转、违规用电；
4. 线路问题：低压线路线径过细、供电半径过大、三相负荷不平衡、线路接地；
5. 采集异常：采集率不足 100%、新增及光伏用户在系统中未调试、采集点挂接错误；
6. 系统配置问题：系统模型配置错误、台区关口计量错误、拓扑不一致。
二、"三排查"方法
1. 大数据排查
通过一体化系统筛选日异常台区，确认采集率是否为 100%；
查看是否有新增及光伏用户未调试；
与营销业务应用系统对比，确认低压用户户变关系是否一致；
在用电信息采集系统中查找异常台区采集点挂接是否正确；
通过 HPLC 查看台区实时线损，把异常台区缩小到某一时间段。
2. 计量排查
通过用电信息采集系统异常监测模块查看台区及低压用户异常用电现象；
分析低压用户电量和台区线损率关系，缩小排查范围；
查看台区供电关口及低压表计 A、B、C 各相电流、电压是否正常，排除关口计量故障。
3. 现场排查
检查低压台区线路走向是否合理，是否存在线径过细、供电半径过大、三相不平衡；
现场核实用户户变关系是否一致；
检查表箱、表计、接户线，核查互感器、电表、采集终端运行状态；
检查低压线路有无私拉乱接、表计体外流转、违规用电行为。
三、线损异常预警阈值
结合台区、客户、线路画像，设置三类预警阈值：
1. 线损异常：日线损率骤升（如由 3% 骤升至 12% 以上）或负损；
2. 数据异常：采集率不足、户变关系不一致、档案不符；
3. 拓扑异常：台区拓扑一致性异常、线路电压合格率低、故障发生率高。
四、治理闭环流程
监控（数据平台实时筛查）→ 派单（工单下发至台区经理）→ 整治（现场核实、消缺、换表、整改线路）→ 反馈（当日
反馈异常原因并完成治理）。核心要求："异常不过夜、治理不隔天"，形成"分析—治理—验收—销号—巩固"长效机
制。
五、典型治理措施
更换烧损的下户线及线路，修复线路接地导致的计量高损；
更换老旧设备，从源头减少线损隐患；
对封印缺失的表计施封，对表计开关及接线螺丝紧固或更换；
核定配变容量、规范设备接线，绘制单线图；
针对低压线路线径细、供电半径长造成的高损台区实施技术改造。
