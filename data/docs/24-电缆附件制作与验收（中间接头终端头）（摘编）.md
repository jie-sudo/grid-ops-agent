# 电缆附件制作与验收（中间接头/终端头）（摘编）

依据 DL/T 1573《电缆附件安装》、GB 50168《电气装置安装工程 电缆线路施工及验收标准》整理。电缆线路多数故
障源于附件安装质量不达标。
一、运行基本要求
1. 导体连接良好：接触电阻小且稳定。新装接头电阻与同长度同截面导线比值 ≤1.1，运行后 ≤1.2；
2. 绝缘可靠：绝缘水平不低于电缆本体，不加速老化；
3. 密封良好：防止水分、潮气侵入，防止绝缘剂流失（避免"呼吸"现象）；
4. 机械强度足够：连接点抗拉强度 ≥ 电缆导体本身抗拉强度 60%；
5. 电场控制完善：采用应力锥等措施改善屏蔽端部电场集中；
6. 接地可靠：接地线截面积 ≥25mm²，金属护层接地电阻 ≤4Ω。
二、制作工艺要点（以热缩型为例）
施工环境：干燥清洁，温度 5℃ 以上，相对湿度 ≤70%；
电缆头一次性连续切剥，剖铅（铝）包光滑无毛刺；
加热收缩温度 120℃~140℃，火焰朝收缩方向旋转移动；
压接：压接管内径比导体外径大 0.2~0.5mm，六角压模分两道压接；
屏蔽恢复：半导电带与电缆屏蔽层搭接 ≥20mm；
外护套密封：与电缆外护套搭接 ≥50mm，防水胶带搭接 ≥30mm；
安全距离：6~10kV 终端头带电引上部分之间及对地距离 ≥200mm。
三、验收标准
项目                                          判据
绝缘电阻（2500V 兆欧表）                             主绝缘对地及相间 ≥100MΩ
直流耐压（10kV）                                  35kV 持续 5 分钟无击穿闪络
交流耐压（推荐）                                    21kV（2.5 倍额定）持续 5 分钟
局部放电                                        ≤10pC（重要电缆）
四、常见缺陷处理
1. 主绝缘划伤/碳化：划伤深度 <0.5mm 用细砂纸打磨；>0.5mm 切除重做；
2. 半导电层断口不齐有毛刺：重新修整、玻璃片刮平；
3. 应力锥位置偏移：拆下重装，与半导电层断口贴合；
4. 压接不牢或端子裂纹：切割重新压接、更换端子；
5. 密封不严进水受潮：切除受潮部分重新制作。
五、敷设要求
10kV 及以上中间接头设置在电缆井或保护管内；直埋电缆中间接头加装保护盒（铸铁/玻璃钢）并埋设标志桩；
35kV 及以上接头制作在恒温恒湿车间，现场制作须搭工棚除湿；
加热收缩类接头温度不足收缩不充分、过高则绝缘过热分解产生内部缺陷。
