## 2 缺陷分级准确率

**样本**：10 条代表性缺陷描述，人工对照 Q/GDW 745-2012 三级定义标注。**结果：10/10 = 100%。**

三级命中规则均正确，无越级/降级误判。

> ⚠️ 样本量仅 10，SRS 正式验收要求 ≥200（每级 ≥50）。本结果证明规则逻辑正确，正式验收需扩充样本。

## 3 意图识别准确率

**方法**：规则层（关键词 + 实体）分类，12 条样本。**结果：11/12 = 91.7%。**

唯一误判：`变压器缺陷按规程怎么处置` 被归为「缺陷分级」（期望「问答」）——该句含"缺陷"又含"处置"，属真歧义。由于意图是软先验、不锁工具，此误判不影响最终答案（循环仍会调知识检索）。

> ⚠️ 仅测规则层；LLM 兜底层未纳入本轮评测。SRS 正式验收要求 ≥700 条、含 LLM 兜底。

## 4 嵌入模型选型（多候选评测）

**方法**：4 个候选模型在 34 篇知识文档上分别入库 + 检索，测 Recall@5/10、MRR、Hit@10 与耗时。

**精度指标**：四模型均满分（1.0），因本轮评测集以"文档标题"为 query、区分度不足，精度差异未能拉开，不作为选型依据。

**耗时指标**（有效区分度）：

| 模型 | 入库耗时 | 单次查询 |
|------|---------|---------|
| bge-small-zh-v1.5 | 3.6s | 58ms |
| m3e-base | 19s | 79ms |
| bge-m3 | 52.6s | 138ms |
| bge-large-zh-v1.5 | 61.9s | 143ms |

**结论：选定 bge-small-zh-v1.5。** 精度无差、查询快 2.5 倍、入库快 20 倍、体积最小（约 100MB）。试点规模下大模型精度优势无法兑现，反而浪费算力。

## 5 LLM 成本与耗时

**方法**：3 个代表性问题（问答/查询/工单）端到端跑一遍，累计统计。

| 指标 | 数值 |
|------|------|
| LLM 调用次数 | 7 |
| 输入 token | 7203 |
| 输出 token | 362 |
| 平均单次延迟 | 1209 ms（最大 1739 ms） |
| 稳态端到端 | ≈3.0s / 问 |
| **估算成本** | **¥0.0023 / 3 问（≈0.0008 元/问）** |

**成本结论**：DeepSeek 单价下（输入 0.27 元/M、输出 1.1 元/M），单问成本不足 1 厘，可忽略。输入 token 占大头源于 ReAct 每步重发系统提示 + 工具 schema + 观察回填，属预期；如需进一步压成本，可精简工具 schema 描述。

## 7 遗留问题与下阶段动作

1. **嵌入评测集重建**：改为"真实问题 → 应命中文档"问答对，重建评测集后复测，才具区分度。
2. **意图评估补 LLM 兜底层** + 样本扩充至 SRS 量级（≥700）。
3. **缺陷分级样本扩充**至 ≥200（每级 ≥50）。
4. **成本单价核对**：DeepSeek 单价按经验值填写，需按实际账单校准。

## 8 对抗压力测试与加固（第二轮）

### 8.1 规则层对抗

| 维度 | 修复前 | 修复后 |
|------|--------|--------|
| 意图规则层 | 11/15 | 15/15 |
| 缺陷分级 | 1/12 | 11/12 |

修复项：漏判不再默认"一般"而降级"人工复核"；补危急词（闪络/爬电/烧毁）；加否定词/时态检测。

### 8.2 LLM 对抗（提示注入 / 幻觉 / 反事实 / 边界）

提示注入 ×3 全部拒绝；反事实 ×2 用条文纠正；库外问题诚实回答；DEV999999 / SQL 注入 / 空消息安全处理。

修复项：实体锚点写入（多轮指代）；幻觉溯源纳入用户输入 + 工具参数；二次确认改 LLM 判断；新增反问/澄清机制（意图低置信 + 实体缺失 + LLM clarify 动作）。

### 8.3 结论

系统已从"硬答"升级为"该反问反问、该降级降级、该给答案给答案"。写操作安全不依赖 LLM 听话程度，而依赖二次确认闸口 + DB 只读角色。
