# 重点对比清单（各模型最可能分歧的条目）

> 用途：多模型盲审时，优先核对下面这些条目。它们要么落在 A/B 分类的边界，要么是 desc 加了 src 没有的数值，最容易出现模型间判断不一致。
> 建议对比时不要只看总 ✓/✗ 数，而看这些条目上各模型是否给出相同判定。

## 一、必看：唯一的 A 类「硬失真」（看其他模型是否也判 ✗）

| 等级-# | src_defect | desc | 我的判定 | 硬依据 |
|---|---|---|---|---|
| 一般-60 | 泄漏电流指示值超标 | 漏电流表上的数比一开始低了，但没归零 | ✗ 删除 | 现象方向相反：超标(偏高) 写成 下降(偏低) |

> 若某模型把这条判 ✗ 且理由是"方向相反"，说明它抓到了硬依据；若判 ✓，说明它把现象失真当成轻微润色。

## 二、发热数值不一致（src 只写「发热」，desc 各编各的数）

| 等级-# | desc 数值 | 备注 |
|---|---|---|
| 一般-9 | 相间温差超过 15K | |
| 一般-24 | 相间温差超了 15 度 | 与 #9 一致 |
| 一般-55 | 相间温差超过 10K | **与 #9/#24 不一致** |
| 危急-4 | 热点>110℃、温差>95% | |
| 危急-57 | 热点>110℃、相对温差>95% | |
| 危急-71 | >90℃ 或相间温差>40K | **与 #4/#57 口径不同** |

> src 均无数值，desc 各自编数且互相矛盾 → 纯 B 类，各模型处理方式会分化。

## 三、程度词偏移（「一阵子」vs「长期」）

| 等级-# | src | desc 措辞 | 问题 |
|---|---|---|---|
| 一般-22 | 仍可以长期运行 | 跑**一阵子** | "一阵子"偏短期，向严重偏移 |
| 一般-72 | 含水量不合格 | 跑**一阵子** | 同上 |
| 一般-41 | 仍可以长期运行 | 长**时间**跑 | 一致 |
| 一般-47 | 仍可以长期运行 | 长期跑 | 一致 |

> 同一 src 四种措辞，"一阵子 vs 长期"是否算失真，各模型会有分歧。

## 四、src 层面矛盾（不是 desc 的错，但会影响等级归类）

| 条目 | src | 标注等级 | 矛盾点 |
|---|---|---|---|
| 一般-5 | 中度锈蚀 | 一般 | 「中度锈蚀」按对照表应=严重(20%~30%) |
| 严重-73 | 中度锈蚀(20%~30%) | 严重 | 同上，两处等级不一致 |
