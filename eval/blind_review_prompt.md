# 缺陷分级闭卷评测 · 盲审任务包

> **使用方法**：把下面「任务指令」整段复制到**全新的、干净的**会话里（每个模型各开一个，不要带任何历史对话）。让模型独立审核后输出 CSV，把 CSV 存盘发回给主会话，用 `compare_reviews.py` 汇总对比。
> 若目标模型无法读本地文件，请把 `qa_closed_defect_review_input.md` 的内容一并粘贴在 prompt 末尾。

---

## 任务指令（从这里开始复制）

你是一位缺陷管理审核员。请逐条审核下面 219 条记录（一般/严重/危急各 73 条），判断口语描述 **desc** 是否忠实表达了原文 **src_defect** 的**缺陷现象**和**严重程度**。

### 一、判定规则（严格执行）

**判为 ✗ 的硬依据（A 类，满足任一即 ✗）**
1. **数值改错**：src 里有具体数值，desc 改了。
2. **现象方向相反**：desc 描述的缺陷方向与 src 相反（如 src「超标(偏高)」被写成「下降(偏低)」）。
3. **等级信号词与标注等级矛盾**：desc 用词明确指向另一等级。

**判为 ✓ 的软判断（B 类，即使 desc 有下列情况也默认 ✓，最多在心里记一笔）**
1. desc 加了 src 没有的数值。
2. 程度词细微偏移（如 src「长期运行」→ desc「跑一阵子」）。
3. src 过简时 desc 的自行具体化（如 src「故障」→ desc「冷却器坏不到 1/3」）。

### 二、等级信号词锚点

| 等级 | 运行影响 | desc 中的口语信号词 |
|---|---|---|
| 一般 | 可长期运行 | 还能接着跑 / 长期跑 / 不影响运行 |
| 严重 | 可短期运行 | 还能撑一阵子 / 凑合 / 眼下还能 |
| 危急 | 不能运行 | 没法运行 / 得赶紧处理 / 影响安全 |

### 三、数值对照（src 有数值时必须一致）

| 缺陷 | 一般 | 严重 | 危急 |
|---|---|---|---|
| 锈蚀(占截面) | <20% | 20%~30% | >30% |
| 歪斜 | 1%~5% | 5%~10% | >10% |
| 电气连接发热 | — | 80℃<T≤90 或 30K<ΔT≤40K | T>90℃ 或 ΔT>40K |
| 漏油速度 | ≥5秒/滴 | ≥5秒/滴 | <5秒/滴 且油位低于下限 |
| 与居民区距离 | — | 规定值 80%~90% | <规定值 80% |
| 绝缘电阻(20℃折算) | — | — | <2000MΩ |
| 绕组温度(危急) | — | — | A95/E110/B120/F145/H175/C210 |

### 四、数据

数据文件：`F:\通用agent\grid-ops-agent\eval\qa_closed_defect_review_input.md`

表格列：`# / 口语描述 desc / 标注等级 / 原文对照 src_defect / ✓✗(空) / 纠正(空)`

### 五、输出要求（严格遵守）

只输出一个 CSV，**不要任何解释、前言、寒暄、markdown 代码块围栏**。格式如下：

```
等级,序号,src,desc,判定,纠正
一般,1,交流耐压和局放测试不合格,耐压和局放这两项试验都没过，数值超了标，但设备还能接着跑。,✓,
严重,2,绝缘油含水量不合格,油样化验结果水份超了，设备还能撑一阵子。,✓,
危急,1,铁心绝缘夹件电阻与以前测试结果有明显变化,...,✓,
```

- **判定列**：只填 `✓` 或 `✗`。
- **纠正列**：判定为 ✓ 时留空；判定为 ✗ 时填**正确等级**（一般/严重/危急）或 `删除`。
- 必须完整输出 219 行，顺序与输入一致。
- **独立判断**，不要受任何已有结论或第三方审核结果影响。
