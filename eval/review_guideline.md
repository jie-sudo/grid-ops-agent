# 缺陷分级闭卷评测集 · 审核规则（多模型对齐用）

> 用途：让不同模型用同一把尺子审核 `qa_closed_defect_review_input.md`，输出结果可直接 diff 对比。

## 一、任务定义

给定每条记录的三列：

| 列 | 含义 |
|---|---|
| `desc` | LLM 生成的口语描述（待审对象） |
| `level` | 自动标注等级（来自缺陷库，视为 ground truth） |
| `src_defect` | 缺陷库原文对照（真实缺陷现象） |

审核目标：判断 `desc` 是否忠实表达了 `src_defect` 的**缺陷现象**和**严重程度**。

输出：忠实打 `✓`；失真在「纠正」栏写**正确等级**或 **`删除`**（失真到无法修复时）。

## 二、判定依据分层（关键！）

### A 类：硬依据（客观，任何模型应给出一致结论）

1. **数值改错**：`src_defect` 里出现的具体数值，`desc` 改了。
   - 例：src=`>30%` → desc=`超过两成`，即错。
2. **现象方向相反**：`desc` 描述的缺陷方向与 `src_defect` 相反。
   - 例：src=`泄漏电流指示值超标`（偏高）→ desc=`比一开始低了`（下降），错。
3. **等级信号词与 level 直接矛盾**：`desc` 用词明确指向另一等级。
   - `一般` 但 desc 说「没法运行/立即处理」；`危急` 但 desc 说「还能长期跑」。

### B 类：软判断（主观，不同模型会产生分歧）

1. **desc 添加 src 没有的数值**：如 src=`发热` → desc=`相间温差超过15K`。src 没给数，无法判定对错，仅看是否与 level 语义一致。
2. **程度词的细微偏移**：如 src=`仍可长期运行` → desc=`还能跑一阵子`（"一阵子"偏短期）。
3. **src 过于简略时的具体化**：如 src=`故障` → desc=`冷却器坏不到1/3`；src=`失灵` → desc=`动作计数器数不准`。是否「张冠李戴」取决于缺陷库上下文，单看无法定论。

**对齐约定（推荐）**：只把 **A 类** 判为 `✗`；**B 类** 默认 `✓`，但把分歧点列入「备注」单独上报，便于跨模型对比时聚焦。

## 三、等级信号词锚点

| 等级 | 运行影响 | desc 中对应的口语信号词 |
|---|---|---|
| 一般 | 可长期运行 | 还能接着跑 / 还能长期跑 / 不影响运行 / 不影响安全 |
| 严重 | 可短期运行 | 还能撑一阵子 / 凑合着跑 / 眼下还能跑 / 暂不影响 |
| 危急 | 不能运行、需立即处理 | 没法接着运行 / 得赶紧处理 / 影响安全运行 / 随时可能 |

## 四、关键数值对照（src 有数值时必须一致）

| 缺陷 | 一般 | 严重 | 危急 |
|---|---|---|---|
| 锈蚀（占截面直径/厚度） | <20%（轻度） | 20%~30%（中度） | >30%（严重） |
| 杆塔歪斜 | 1%~5% | 5%~10% | >10% |
| 电气连接发热 | 温差≤30K | 80℃<T≤90 或 30K<温差≤40K | T>90℃ 或 温差>40K |
| 绕组/热点温度（危急） | — | — | A级95/E级110/B级120/F级145/H级175/C级210 |
| 漏油速度 | ≥5秒/滴（慢） | 同左 | <5秒/滴 且油位低于下限 |
| 与居民区距离 | — | 规定值的 80%~90% | <规定值的 80% |
| 绝缘电阻折算 20℃ | — | — | <2000MΩ |
| 断股截面损失 | <7%（一般） | 7%~25%（严重档） | >25%（危急） |
| 杆顶挠度 | — | 直线7~10‰/直线转角10~15‰/耐张22~24‰ | — |

## 五、已知的 src 层面问题（非 desc 失真，供复核缺陷库）

- 「中度锈蚀」同时出现在 一般#5 与 严重#73（等级矛盾）。
- 「绝缘油含水量不合格」「绝缘电阻不合格」「局放/耐压/介损不合格」等同一条 src 在多个等级出现，需靠 desc 的程度词区分，容易产生 B 类分歧。
- 一般表「发热」三条 desc 数值不一致（#9/#24 用 15K，#55 用 10K）。
